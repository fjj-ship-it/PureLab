## APK 构建完成（18:30）

- 产出 `purelab-apk/PureLab-v1.0-debug.apk`（50KB，v2+v3 签名验证通过，包名 com.purelab.app v1.0，minSdk 24 / targetSdk 35）。
- 无 Gradle 构建链跑通：javac → d8 → aapt2 compile/link → Python zipfile 注 dex → zipalign → keytool → apksigner。脚本：`purelab-apk/build.sh`、`add_dex.py`、`make_icons.py`（PIL 生成 5 档 mipmap 图标）。
- Git Bash 踩坑（可复用）：
  1. Windows 原生 exe（javac/aapt2/python）收 bash 的 `/c/...` 路径解析不了，必须 `cygpath -w` 转 `C:/` 风格；d8.bat/apksigner.bat 内部调 java 同理。
  2. JDK17 下 javac 不要用 `-bootclasspath android.jar`（报 java.lang 找不到），改 `-classpath` 即可。
  3. d8 `--output .` 相对当前 cwd（当时在 build/obj），注意 cd 位置。
  4. zipalign 对 Python zipfile 注入的条目报 "header mismatch" 警告，可忽略，产物完整性校验通过。
- APK 内容核验：assets/www 三件套 + classes.dex + 5 档图标 + resources.arsc 齐全，testzip OK。
- 交互预览：index.html 可在浏览器直接打开（localStorage 数据 + 纯前端路由）。
